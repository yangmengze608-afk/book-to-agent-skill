# Limitations

> Where the method breaks, as stated by the book itself (chapter 8) and as
> inferred for agent use. Never present the method as universal.

### L1. Slow feedback loops defeat calibration
- type: SOURCE FACT
- source: chapter 8, section "The Practicing Decider"
- source_confidence: high

If outcomes take a decade to arrive, a personal decision journal cannot
correct you within a career. The book's own remedy: lean on base rates from
other people's histories instead of your own track record. Agent use: when
the user's feedback loop is slow, switch from "journal and calibrate" to
"find the reference class" - and say why the switch happened.

### L2. One-off, high-stakes choices deserve external counsel
- type: SOURCE FACT
- source: chapter 8, section "The Practicing Decider"
- source_confidence: high

The method is built on repeated decisions with eventual feedback.
One-off, high-stakes choices get less from personal calibration; the book
recommends external counsel there. Agent use: recommend consulting
domain-appropriate humans; do not simulate confidence the user cannot
actually accumulate.

### L3. The apparatus goes dark under blame
- type: SOURCE FACT
- source: chapter 8, section "The Practicing Decider"
- source_confidence: high

The whole system assumes people can stomach being visibly wrong on the
record. If the culture punishes journaled errors, people stop journaling,
and calibration data dies. Agent use: when generating journal entries or
reviews for a team, keep the tone tuition-collecting, not blame-assigning;
if the user hints at a blame culture, warn that the journal only works
while it is safe.

### L4. Structuring is not predicting
- type: DISTILLER INFERENCE
- derived_from: P1, P4, L1, L2

This skill reduces error rate given uncertainty and blindness to one's own
error rate; it does not reduce the world's uncertainty (the book says the
tools "do not reduce the uncertainty of the world by one iota"). An agent
using this skill must not present bet-framing or calibration numbers as
forecasts of what will happen - they are statements about the decider, not
the dice.
