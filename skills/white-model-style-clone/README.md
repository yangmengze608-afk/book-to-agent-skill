# White Model Style Clone

一个面向“直接风格迁移太脏、太碎、细节失控”问题的两阶段图像工作流。

它先把结构源转成无纹理哑光白模，锁定镜头、人物、姿态、主要物件和负空间；随后把参考图严格限制为配色、光线、材质类别与大尺度明暗来源，再进行受控上色。

## 适用场景

- 参考图本身颗粒、烟尘或装饰很多，直接迁移会放大脏污；
- 批量故事图需要统一构图纪律和干净材质；
- 需要抑制模型擅自添加纹样、挂件、文字、碎屑或背景物；
- 需要同时保留白模与最终上色图，便于逐阶段审查。

## 与 Image Style Clone 的关系

本 Skill 与 `image-style-clone` 并列，不替换它。普通视觉 DNA 提取和风格复刻继续使用 `image-style-clone`；当清洁度或细节抑制是核心目标时，使用本 Skill。
